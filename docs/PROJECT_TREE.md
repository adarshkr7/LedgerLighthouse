## How to read this tree

The directory split *is* the trust model. Three lines matter more than the rest:

- **`services/orchestrator/` is untrusted.** It reads attacker-controlled text and holds a gas-only relay key. It must never be able to import `services/signer/` **or `services/vendor-aisa/`**, and [`scripts/check-boundary.mjs`](../scripts/check-boundary.mjs) fails CI if it can.
- **`services/signer/` holds the only key that can move the user's money.** It reads the chain and accepts `(goalId, seq)` from callers. Nothing else.
- **`services/vendor-aisa/` holds the only key that can spend at a paid API.** A different credential from the model gateway's, deliberately with no fallback between them — two names exist so two components hold two secrets.
- **`contracts/` is where policy actually lives.** Not in TypeScript, not in a prompt, not in a config file.

Dependency direction, which no file may violate:

```
packages/shared/       ->  (nothing)
contracts/             ->  (nothing)
services/trace/        ->  shared/
services/signer/       ->  shared/
services/facilitator/  ->  shared/
services/vendor-aisa/  ->  shared/
services/orchestrator/ ->  shared/ + trace/
apps/web/              ->  orchestrator  (HTTP + SSE only)
```

## Where each guarantee is enforced

| Guarantee | Enforced in |
|---|---|
| The budget stays secret | [`contracts/src/PolicyVault.sol`](../contracts/src/PolicyVault.sol) — `euint256`, never a plaintext balance |
| The debit commits before the decision is knowable | Same file — `e.select` inside `requestSpend` |
| An approval cannot be forged | Same file — `e.verifyDecryption` against the stored handle |
| The agent cannot obtain a signature | [`services/signer/src/schema.ts`](../services/signer/src/schema.ts) — the request carries `(goalId, seq)` and nothing else |
| A sweep cannot be redirected | [`services/signer/src/service.ts`](../services/signer/src/service.ts) — the payee is read from `Goal.owner`, and an open goal is refused |
| The agent cannot reach the key | [`scripts/check-boundary.mjs`](../scripts/check-boundary.mjs) — import boundary, enforced in CI |
| The agent cannot reach the paid API's credential | Same file — `services/vendor-aisa` and `AISA_VENDOR_KEY` are both forbidden names in the orchestrator |
| Prices cannot drift between charged and displayed | [`packages/shared/src/demo/catalog.ts`](../packages/shared/src/demo/catalog.ts) — one definition, every consumer |
| A hostile vendor cannot script the browser | [`packages/shared/src/demo/search-result.ts`](../packages/shared/src/demo/search-result.ts) — rendering rules live where they can be tested |
| The vendor cannot be griefed into spending | [`services/vendor-aisa/src/handler.ts`](../services/vendor-aisa/src/handler.ts) — `/verify` and a persisted hourly ceiling, both before the upstream call |
| A run can be verified by a stranger | [`services/trace/src/verify.ts`](../services/trace/src/verify.ts) — trace file plus a public RPC |
| A trace cannot be backdated | [`contracts/src/TraceAnchor.sol`](../contracts/src/TraceAnchor.sol) — first-write-wins, one root per goal |
| A trace survives a restart | [`services/orchestrator/src/trace-store.ts`](../services/orchestrator/src/trace-store.ts) — written to disk before it is served |
| The services are not reachable by default | [`packages/shared/src/node/guard.ts`](../packages/shared/src/node/guard.ts) — loopback bind, origin allowlist, rate limits |
